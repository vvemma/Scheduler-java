# Schedule Planner

Java Swing으로 만든 월간 일정 관리 프로그램입니다.
달력에서 날짜를 눌러 일정을 보고, 추가·수정·삭제할 수 있습니다. 일정은 텍스트 파일(`schedule-normal.data`)에 저장됩니다.

## 주요 기능

- **월간 달력**: `<` `>` 버튼으로 이전 달과 다음 달로 이동합니다. 날짜 칸에는 그날의 일정 제목이 표시됩니다.
- **일정 보기**: 날짜를 누르면 아래 패널에 그날의 일정(제목, 시작·종료 시간, 장소, 메모)이 나타납니다.
- **일정 추가·수정**: 내용을 입력하고 `Save`를 누르면 저장됩니다. 그날 일정이 이미 있으면 그 일정을 새 내용으로 바꿉니다.
- **일정 삭제**: `Cancel`을 누르면 선택한 날짜의 일정을 삭제하고 패널을 닫습니다.
- **패널 닫기**: `Close`를 누르면 저장하지 않고 패널만 닫습니다.
- **파일 저장**: 추가·수정·삭제할 때마다 데이터 파일에 바로 저장됩니다.

## 실행 환경

- JDK 17 이상
- 외부 라이브러리 없음 (Java 표준 라이브러리의 Swing만 사용)

## 실행 방법

### IntelliJ IDEA

1. 프로젝트 폴더를 엽니다.
2. `src/Test.java`의 `main`을 실행합니다.

### 명령줄

프로젝트 폴더에서 실행해야 `schedule-normal.data`를 찾을 수 있습니다.

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out Test
```

프로그램은 2026년 5월 달력으로 시작합니다. 시작 달은 `Test.java`에서 바꿀 수 있습니다.

## 사용 방법

1. 달력에서 날짜를 누릅니다.
2. 아래 입력 칸에 내용을 적습니다.
   - `Title`: 일정 이름 (필수)
   - `Start Time`: 시작 시간, `HH:mm` 형식 예: `09:30` (필수)
   - `End Time`: 종료 시간, `HH:mm` 형식 (선택)
   - `Place`, `Memo`: 장소와 메모 (선택)
3. `Save`를 누르면 저장됩니다.

## 데이터 파일 형식

일정 하나는 `KEY = 값` 줄 여러 개로 적고, `;` 한 줄로 일정을 구분합니다.

```
// 주석은 //로 시작합니다
TITLE = Semester Starts
START = 2026-03-02 13:00
END = 2026-03-02 13:50
PLACE = EClass
MEMO = 첫 수업
;
```

| 키 | 필수 | 형식 |
|---|---|---|
| `TITLE` | O | 문자열 |
| `START` | O | `yyyy-MM-dd HH:mm` |
| `END` | X | `yyyy-MM-dd HH:mm` |
| `PLACE` | X | 문자열 |
| `MEMO` | X | 문자열 |

파일을 읽을 때 아래 일정은 건너뛰고 콘솔에 이유를 출력합니다.

- `TITLE`이나 `START`가 없는 일정
- 시간 형식이 잘못된 일정
- 종료 시간이 시작 시간보다 앞선 일정

## 프로젝트 구조

```
src/
├── Test.java                  # 프로그램 시작점 (main)
├── SchedulePlannerFrame.java  # 메인 창, 패널들을 연결하고 이벤트 처리
├── MonthTopPanel.java         # 상단: 연·월 표시와 이전/다음 달 버튼
├── MonthSchedulePanel.java    # 가운데: 7×6 달력 버튼
├── DaySchedulePanel.java      # 하단: 선택한 날짜의 일정 입력 칸과 버튼
├── Schedule.java              # 일정 하나 (제목, 시작·종료 시간, 장소, 메모)
└── ScheduleList.java          # 일정 목록, 파일 읽기·저장
schedule-normal.data           # 일정 데이터 파일
```

## 알려진 제한

- 하루에 일정 하나만 다룹니다. 같은 날 일정이 여러 개면 달력과 입력 패널에는 그중 하나만 보입니다.
- 시간은 `HH:mm` 형식으로 입력해야 합니다. 다른 형식으로 입력하면 저장되지 않습니다.
